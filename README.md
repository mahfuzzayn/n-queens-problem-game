# N-Queens Puzzle Game

A **game-centric N-Queens puzzle game** with a Clash of Clans-inspired visual style. Place N queens on an N×N chessboard so that no two queens attack each other.

## Repository Layout

| Folder | Description |
|--------|-------------|
| `web-app/` | Next.js web application (Phase 1 — active development) |
| `mobile-app/` | React Native app (Phase 2 — planned) |

## Quick Start (Web App)

```bash
cd web-app/n-queens-problem-game
npm install
npm run dev      # Start development server
npm test         # Run tests
npm run build    # Production build
```
