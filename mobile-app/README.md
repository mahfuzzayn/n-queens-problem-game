# N-Queens Game — Mobile App (Phase 2)

## Plan
- **Framework:** React Native with Expo + TypeScript
- **Code sharing:** Reuse `core/` and `config/` from `web-app/` unchanged
- **Replacements:**
  - Web Audio → `expo-av`
  - `navigator.vibrate` → `expo-haptics`
  - `localStorage` → `AsyncStorage`
  - Framer Motion → `react-native-reanimated`
- **Design:** Recreate the same design language with native components (Skia or SVG for queens and bevels)

🚧 Not started. See `web-app/n-queens-problem-game/docs/ROADMAP.md` for the plan.
